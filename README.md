# 🎾 테니스 동호회 실시간 대회 전광판 & 대시보드
# (Tennis Club Live Tournament Dashboard & Management System)

대회 현장(대형 TV / 빔프로젝터 전광판)과 참가 선수들의 스마트폰 어디서나 실시간으로 연동되는 **테니스 동호회 실시간 대회 운영 시스템**입니다.

## 🌟 주요 기능
1. **스타디움 전광판 네온 다크 뷰**:
   - 실시간 순위보드 (승점 > 득실차 > 다득점)
   - 코트별 시계열 매치 카드 (1~3번 코트 30분 단위)
   - 경기 속보 및 코트 호출 실시간 피드
   - 현장 스마트폰 즉시 접속용 QR 코드 내장
2. **모바일 퍼스트 반응형 뷰**:
   - 순위 / 코트 / 내 경기 일정 / 속보 / 회원 명단 5대 하단 탭
   - 본인 출전 경기만 쏙 뽑아보는 "내 경기 모아보기"
3. **대회 모드 이원화**:
   - 🎉 **이벤트 게임**: 친선전, 번외 매치, 핸디캡전
   - 🏆 **정기전 (개인 리그전)**: 전 경기 복식(2 vs 2) 진행 & 개인별 승점/득실차 누적
   - 👥 **정기전 (조별 대항전)**: A, B, C, D 4개조 팀 리그전
4. **4대 대진표 편성 엔진**:
   - 경기이사 수동 배정
   - 개인 레벨(NTRP) 밸런스 자동 대진
   - A~D조 조장 대진 세팅
   - 연간/시즌 누적 순위표 자동 연동
5. **동호회 회원 명단 관리**:
   - 회원 추가, 수정, 출전/불참/탈퇴 상태 전환, 대량 텍스트 일괄 등록 지원
